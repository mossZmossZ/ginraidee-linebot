# Planning tracker

For this planning draft, cards live locally under
`.scratch/ginraidee/issues/`, indexed by `docs/kanban.md`.

This is a reversible repository-local planning choice made to fulfill the
requested plan/todo/board. It does not configure or publish external issues.
Card 00 reviews whether to retain it for development. No external tracker,
triage automation, agent instruction file, or execution configuration has been
created by this planning step.

Use numbered card files in dependency order. Each contains expected behavior,
blocked-by links, status, todo items, acceptance criteria and review evidence.
Keep the board and card statuses synchronized. Do not mark draft cards
ready-for-agent before the plan and their dependencies are accepted.

After three failed developer/tester rounds, use Pending on the parent and a
linked Bug record; preserve rounds and continuation evidence. Definitions are
in `docs/development-workflow.md` and require review through card 00.
